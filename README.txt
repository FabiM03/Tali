1. Hozz létre ingyenes fiókot: https://www.emailjs.com
2. Készíts Email Service-t (Gmail vagy Outlook).
3. Készíts egy Email Template-et.

Template példa:

Nev: {{name}}

Programok:
{{programs}}

Datumok:
{{dates}}

Megjegyzes:
{{note}}

4. script.js fájlban cseréld ki:

PASTE_PUBLIC_KEY_HERE
PASTE_SERVICE_ID_HERE
PASTE_TEMPLATE_ID_HERE

értékeket a saját EmailJS adataidra.

5. GitHub:
- Új repository
- Fájlok feltöltése
- Settings -> Pages
- Deploy from branch -> main

Kész.
